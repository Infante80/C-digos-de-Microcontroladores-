# C-digos-de-Microcontroladores-
Este repositorio contendrá todos los códigos de Microcontroladores, se vera una constante actualización en los mismos.
Al ser creado en PlatformIO es necesario usar un archivo que lleva la extencion .ini para no subir cada archivo .ini
solo se usara el .ini que se ve en este repositorio, realmente lo unico que importa en este archivo es la velocidad del
monitor serial.
